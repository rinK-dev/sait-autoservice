Система:
Первый зарегистрированный аккаунт = manager.
Manager через сайт создаёт приглашение.
Новый механик открывает ссылку и сам задаёт пароль.
Обычный mechanic не может добавлять других.
Manager может блокировать mechanics.
Mechanic добавляет работы и детали автомобиля.
Client видит только свои машины и историю.

Frontend API: http://localhost:8080/api
schema.sql — пример PostgreSQL.

Для реального запуска C++ backend нужно подключить Crow, libpqxx и безопасное
хеширование паролей. Не хранить пароли в открытом виде.
